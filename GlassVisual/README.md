# NULL Client

Клиентский Fabric-мод для **Minecraft 1.21.4** и **Java 21**. Проект сохраняет существующую структуру GlassVisual и постепенно развивается в NULL.

## Интерфейс

- **Right Shift** — открыть ClickGUI.
- Тёмная графитовая тема с фиолетовым акцентом, карточками, категориями и поиском.
- Обычный читаемый шрифт Inter вместо пиксельного Minecraft-шрифта в ClickGUI, HUD и редакторе.
- Переключение русского и английского языков.
- ClickGUI всегда помещается в экран; масштаб меняется кнопками − / + в боковой панели. Окно и изображение игры он не трогает.
- Шрифт Inter (SIL OFL, см. `assets/glassvisual/font/LICENSE-Inter.txt`) вместо пиксельного.
- ПКМ по модулю или значок настроек открывает его параметры (слайдеры, переключатели, выбор режима и цвета).
- **Right Alt** — открыть glass HUD Editor: перетаскивай HUD-блоки и панель хотбара мышкой; позиции сохраняются.
- Настройки сохраняются в `.minecraft/config/glassvisual.json`.

## Рабочие модули

### Combat
- Aim Assist — плавная доводка прицела к видимым игрокам вблизи, только пока удерживается атака. Может нарушать правила серверов и привести к блокировке.
- Target HUD — имя, скин (если доступен), здоровье, дистанция и плавная полоса здоровья.
- Hit Visuals — короткий маркер при снижении здоровья цели под прицелом.
- Combat HUD — предмет в руке и индикатор перезарядки удара.
- HUD Particles — собственные 2D-частицы NULL поверх HUD.

### Movement
- Auto Sprint.
- Sprint Display.
- Jump Stats.
- Speed Graph.
- Keystrokes.

### Visuals
- **Screen Stretch** — настоящее растягивание изображения мира (Mixin в `GameRenderer.getBasicProjectionMatrix`, только 3D-матрица проекции). Режимы 4:3, 16:9 и Stretch с ползунком 0.50x–2.00x. HUD, текст, инвентарь и меню не затрагиваются; размер окна, fullscreen и масштаб интерфейса не меняются.
- **World Particles** — собственные 3D-частицы в мире (без `ParticleTypes`): плотность, дальность, размер, искры при движении.
- **Player Trail** — светящийся 3D-шлейф за игроком: длина, толщина, свечение и его яркость, скорость затухания, 6 цветов. Сбрасывается при телепорте и смене измерения.
- World Tint — лёгкий оттенок игрового экрана.
- Block Outline — цветная обводка блока под прицелом.
- **Crosshair** — собственный прицел NULL вместо стандартного, с подсветкой цели.
- FPS Counter.
- Potion HUD.
- Time Changer — локально фиксирует время мира на полдень.

### Player
- Armor Status — прочность каждой части брони.
- Totem Counter — количество тотемов в инвентаре и второй руке.
- Food HUD — голод и насыщение.
- XP HUD — уровень и прогресс опыта.
- Armor HUD — иконки брони и полосы прочности.
- Coordinates.
- Durability — прочность предмета в основной руке.
- **Inventory** — собственная glass-панель из девяти слотов вместо стандартного хотбара; её можно двигать в HUD Editor.

### Misc
- Session Info.
- Clock.
- ArrayList.
- Notifications.
- Ping.
- Direction — сторона света по направлению взгляда.

## Пока не реализовано

В дальнейшей работе остаются полноценный sky editor, настройка положения руки/предмета и расширенные параметры модулей. Aim Assist — экспериментальная функция: используй её только там, где это разрешено правилами сервера.

## Требования

- Java 21
- Minecraft 1.21.4
- Fabric Loader 0.16.10 или новее
- Fabric API 0.119.2+1.21.4

## Сборка

Из папки `GlassVisual`:

```bash
gradle build
```

Основной JAR находится в `build/libs/glass-visual-1.2.0.jar`. В папку `.minecraft/mods` помещается только основной JAR, не `*-sources.jar`.

## Управление

| Клавиша | Действие |
|---|---|
| Right Shift | Открыть / закрыть ClickGUI |
| Right Alt | Открыть редактор HUD |
| ESC | Закрыть открытый экран |

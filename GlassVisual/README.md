# NULL Client

Клиентский Fabric-мод для **Minecraft 1.21.4** и **Java 21**. Проект сохраняет существующую структуру GlassVisual и постепенно развивается в NULL.

## Интерфейс

- **Right Shift** — открыть ClickGUI.
- Светлая, контрастная тема с карточками, категориями, поиском и цветовым акцентом.
- Обычный читаемый текст без декоративных псевдошрифтов и нечитаемых символов.
- Переключение русского и английского языков.
- Режимы раскладки FIT, 4:3 и STRETCH.
- **Right Alt** — открыть редактор HUD и перетаскивать элементы.
- Настройки сохраняются в `.minecraft/config/glassvisual.json`.

## Рабочие модули

### Combat
- Target HUD — имя, скин (если доступен), здоровье, дистанция и плавная полоса здоровья.
- Hit Visuals — короткий маркер при снижении здоровья цели под прицелом.
- Combat HUD — предмет в руке и индикатор перезарядки удара.
- Particles — собственные 2D-частицы NULL.

### Movement
- Auto Sprint.
- Sprint Display.
- Jump Stats.
- Speed Graph.
- Keystrokes.

### Visuals
- World Tint — лёгкий оттенок игрового экрана.
- Crosshair — акцентный прицел поверх стандартного.
- FPS Counter.
- Potion HUD.
- Time Changer — локально фиксирует время мира на полдень.

### Player
- Armor Status — прочность каждой части брони.
- Armor HUD — иконки брони и полосы прочности.
- Coordinates.
- Durability — прочность предмета в основной руке.
- Inventory — девять слотов хотбара.

### Misc
- Session Info.
- Clock.
- ArrayList.
- Notifications.
- Ping.

## Пока не реализовано

Aim Assist и Block Outline пока не включены: они не должны отображаться как работающие функции, пока не будут реализованы и проверены. Также в дальнейшей работе остаются полноценный sky editor, настройка положения руки/предмета и расширенные параметры модулей.

## Требования

- Java 21
- Minecraft 1.21.4
- Fabric Loader 0.16.10 или новее
- Fabric API 0.119.2+1.21.4

## Сборка

Из папки `GlassVisual`:

```bash
gradle build
```

Основной JAR находится в `build/libs/glass-visual-*.jar`. В папку `.minecraft/mods` помещается только основной JAR, не `*-sources.jar`.

## Управление

| Клавиша | Действие |
|---|---|
| Right Shift | Открыть / закрыть ClickGUI |
| Right Alt | Открыть редактор HUD |
| ESC | Закрыть открытый экран |
